# Contributing

Thanks for helping! The most useful contribution is a **speaker report**: open a
[Speaker compatibility report](../../issues/new?template=speaker-report.yml) with the settings
that worked for your model. They are collected in the README table.

Code changes: `npm install`, `npm test`, `npm start`. Keep PRs small, add a unit test for
anything in `src/renderer/synth.js`, and add new UI text to both languages in `src/renderer/i18n.js`.
